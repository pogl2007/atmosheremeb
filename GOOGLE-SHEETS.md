# Заявки в Google Таблицу

Как сделать, чтобы заявка с сайта сама падала строкой в таблицу, и как вести
по ней клиента: замер → проект → договор → производство → доставка.

Telegram при этом остаётся. Он мгновенный и нужен, чтобы не пропустить
заявку. Таблица нужна, чтобы не потерять клиента через две недели.

---

## Как это работает

Готового «подключения Google Таблиц» у сайта на PHP нет, и городить доступ
через официальный Google API не стоит: там служебные аккаунты, ключи в
JSON, подпись токенов — много деталей, которые ломаются.

Способ проще и надёжнее: **Apps Script**. Это скрипт, который живёт внутри
самой таблицы. Мы разворачиваем его как веб-адрес, и сайт шлёт туда заявку
обычным POST. Скрипт дописывает строку.

```
форма на сайте  →  submit.php  →  Telegram          (сразу, вам в телефон)
                              →  Apps Script → строка в таблице
                              →  журнал админки
```

Ничего платить не нужно, лимитов при вашем потоке не будет.

---

## Шаг 1. Таблица

Создайте таблицу, первый лист назовите **Заявки**. Первая строка — шапка:

| A | B | C | D | E | F | G | H | I | J |
|---|---|---|---|---|---|---|---|---|---|
| Дата | Имя | Телефон | Связь | Заявка | Страница | Стадия | Следующий шаг | Сумма | Комментарий |

Закрепите первую строку: **Вид → Закрепить → 1 строка**.

### Стадии

В столбце **Стадия** сделайте выпадающий список: выделите столбец G,
**Данные → Проверка данных → Раскрывающийся список**, и впишите:

```
Новая
Замер назначен
Замер сделан
Проект готов
Договор подписан
В производстве
Доставка
Завершена
Отказ
```

Порядок неслучайный — он повторяет ваш процесс. Клиент двигается сверху
вниз, и по столбцу сразу видно, где кто застрял.

### Чтобы просроченные подсвечивались

Смысл всей затеи — не в списке заявок, а в том, что видно, кому пора
звонить. Столбец **Следующий шаг** — дата, а не текст.

Выделите строки, **Формат → Условное форматирование → Своя формула**:

```
=И($H2<СЕГОДНЯ(); $H2<>""; $G2<>"Завершена"; $G2<>"Отказ")
```

Заливка — красная. Теперь всё, где дата прошла, а клиент не закрыт, горит
красным. Открыли таблицу утром, увидели красное — это и есть список дел.

## Шаг 2. Скрипт

В таблице: **Расширения → Apps Script**. Удалите то, что там есть, и
вставьте:

```javascript
// Принимает заявку с сайта и дописывает строкой в лист «Заявки».
// Секрет нужен, потому что адрес скрипта открыт всему интернету:
// без него любой, кто его узнает, сможет засорять таблицу.
const СЕКРЕТ = 'замените-на-длинную-случайную-строку';

function doPost(e) {
  let д;
  try {
    д = JSON.parse(e.postData.contents);
  } catch (err) {
    return ответ({ ok: false, error: 'bad json' });
  }

  if (д.secret !== СЕКРЕТ) return ответ({ ok: false, error: 'forbidden' });

  const лист = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('Заявки');
  лист.appendRow([
    new Date(),
    д.name || '',
    д.phone || '',
    д.contact || '',
    д.text || '',
    д.page || '',
    'Новая',
    '',
    '',
    ''
  ]);

  return ответ({ ok: true });
}

function ответ(о) {
  return ContentService
    .createTextOutput(JSON.stringify(о))
    .setMimeType(ContentService.MimeType.JSON);
}
```

Замените `СЕКРЕТ` на длинную случайную строку — например, отбейте
30 случайных символов с клавиатуры. Запомните её, она понадобится дальше.

---

## Шаг 3. Публикация

**Начать развёртывание → Новое развёртывание → тип: Веб-приложение.**

- **Запуск от имени:** я (ваш аккаунт);
- **Доступ:** все.

«Все» звучит страшно, но иначе сайт не сможет достучаться: сервер приходит
без вашего входа в Google. Именно поэтому в скрипте есть секрет — он и
есть пропуск. Таблицу при этом никто посторонний не увидит, доступен только
скрипт, и только на запись строки.

Google один раз попросит подтвердить разрешения — это нормально, скрипт
ваш собственный.

Скопируйте выданный адрес, он вида
`https://script.google.com/macros/s/AKfy.../exec`.

## Шаг 4. Сайт

В `public/config.php` добавьте две строки:

```php
define('SHEETS_URL',    'https://script.google.com/macros/s/AKfy.../exec');
define('SHEETS_SECRET', 'та-самая-длинная-случайная-строка');
```

Дальше — правка `public/api/submit.php`. Скажите, и я её внесу: там
добавляется одна функция и один вызов рядом с отправкой в Telegram.

Важный принцип, тот же, что и с журналом: **таблица не должна ронять
заявку**. Сначала уходит Telegram, и только потом строка в таблицу. Если
Google недоступен, клиент всё равно получит «спасибо», а вы — сообщение в
телефон. Ошибка уйдёт в лог сервера, а не на экран посетителю.

Отдельная тонкость: Apps Script отвечает редиректом, поэтому в curl
обязателен `CURLOPT_FOLLOWLOCATION`. Без него запрос выглядит успешным,
а строка не появляется.

---

## Как этим пользоваться

Таблица работает, только если у каждой строки заполнен **Следующий шаг**.
Это единственное правило, без него всё превращается в список, который никто
не открывает.

Позвонили клиенту — сразу ставите дату следующего касания. Договорились о
замере на четверг — ставите четверг. Замерщик съездил — двигаете стадию и
ставите дату, когда обещали проект.

Раз в неделю полезно смотреть, сколько строк в каждой стадии. Если из
десяти замеров до договора доходит один — проблема не в сайте и не в
рекламе, а в том, что происходит после замера.

---

## Когда таблицы станет мало

Признаки: заявок больше 20 в месяц, менеджеров больше одного, начали
путаться, кто кому звонил. Тогда — Битрикс24 (бесплатный тариф до 5
человек) или amoCRM.

Переезжать будет несложно: и та, и другая принимают заявки таким же
webhook, а накопленную таблицу можно загрузить как есть. Поэтому начинать
с таблицы не тупик — это нормальный первый шаг.
